## 第 0 章 · 课程与平台总览(2 课时)

| 讲 | 主题 | 知识点 | 实操 |
|---|---|---|---|
| 0-1 | 行业/岗位/能力模型 + 平台架构总览 | 岗位能力拆解;转型路径;平台 20 项能力;工业件(GraphQL/Pulsar/读写分离/多级缓存)在课程中的落位 | Lab0:git clone 平台仓,`make setup && make infra`,跑通第一个 GraphQL 查询与 SSE 流 |

## 第 1 章 · LLM API、Prompt 与结构化输出(8 课时)

| 讲 | 主题 | 知识点 | 对应工程 |
|---|---|---|---|
| 1-1 | LLM API 与模型调用基础 | Chat Completions/Responses;参数(temperature/top_p/max_tokens);Token 与 Context Window;错误类型与重试 | `gateway/domain.py`(已完成 TDD) |
| 1-2 | Streaming 流式输出 | SSE 协议;FastAPI StreamingResponse;前端消费;中断取消;断点保存 | `api/app.py` SSE 端点 |
| 1-3 | Prompt Engineering | System Prompt 职责;角色约束;Few-shot;任务拆解;模板化;注入风险;版本管理思想 | `gateway/prompt.py`(Lab1 产出) |
| 1-4 | Structured Output + Gateway 集成 | JSON Schema/Pydantic;原生结构化输出;校验-重试-降级;多模型路由与 fallback | `gateway/schema_out.py` + `router.py` |

**Lab1(验收标准)**:①Mock Provider 单测全绿且覆盖 ≥80%;②SSE 打字机效果;③主模型故障自动 fallback;④结构化输出非法 JSON 反喂重试成功。→ 里程碑 M1

## 第 2 章 · Function Calling、Tool Runtime 与 MCP(10 课时)

| 讲 | 主题 | 知识点 |
|---|---|---|
| 2-1 | Function Calling 与 Tool Use 原理 | 工具定义/Input/Output/Error Schema;工具选择机制 |
| 2-2 | Tool Registry 设计 | 注册/发现/元数据/分类/版本/依赖/启停 |
| 2-3 | 工具治理与安全边界 | 参数校验;RBAC 与身份透传;只读/写/高风险分级;白名单;SQL/Shell 风控;人工确认;脱敏;超时恢复 |
| 2-4 | MCP 协议 | MCP 基础;文件系统/数据库/GitHub/内部服务接入;权限与审计;连接管理 |
| 2-5 | 阶段集成 + Pulsar 审计流 | 工具调用审计事件(Pulsar 生产者);CLI 调试入口;Trace 留痕 |

**Lab2 验收**:注册 5+ 工具;高危工具需人工确认;审计事件可在 Pulsar 消费端核对;参数非法被 Schema 拦截。→ M2

## 第 3 章 · Agent Loop、State Machine 与 Codebase Agent(10 课时)

| 讲 | 主题 |
|---|---|
| 3-1 | 从 Tool Agent 到 Agent Loop(ReAct/Plan-Execute/五段循环/终止条件/死循环识别) |
| 3-2 | Planning 与任务拆解(一次性 vs 动态计划/偏差处理/何时不用 Planner) |
| 3-3 | State Machine 与 Checkpoint(9 态任务状态/步骤状态/中断恢复/人工接管) |
| 3-4 | Sandbox 与执行边界(文件/Shell/网络三类边界;本地 vs Docker 沙箱;审计回放) |
| 3-5 | Agent Harness + LangGraph 编排 + Codebase Agent 集成(十类代码工具;代码理解/测试修复两任务) |

**Lab3 验收**:Agent 在演示仓库完成"找出登录逻辑并输出文档";kill 进程后从 Checkpoint 恢复继续;危险命令被 Sandbox 拦截。→ M3

## 第 4 章 · Context Engineering、Memory 与 Codebase RAG(10 课时)

| 讲 | 主题 |
|---|---|
| 4-1 | Context Engineering(Packing/Prioritization/Budget/Compression/污染/KV Cache/LiteLLM 路由) |
| 4-2 | Working Memory 与任务上下文(Scratchpad/生命周期/与 Agent State 边界) |
| 4-3 | Memory 体系(短期/长期/项目级;记忆 CRUD 与可信度;策略对比) |
| 4-4 | 现代 RAG(解析/Chunking 六法/Embedding/Hybrid Search/Query Rewrite/Rerank/Citation) |
| 4-5 | LLM Wiki 知识治理 + Codebase RAG 集成(AST 分块/混合检索/项目记忆/Context Debug Report) |

**Lab4 验收**:三个典型问题(鉴权链路/新支付渠道影响面/异常根因)回答均带文件+行号引用;长文件压缩后 Token 消耗下降可量化。→ M4

## 第 5 章 · Multi-Agent、Skill 与 Agent Eval(10 课时)

| 讲 | 主题 |
|---|---|
| 5-1 | Multi-Agent 模式与边界(单/多 Agent 适用;Supervisor/Planner-Executor/Reviewer;隔离与预算;冲突仲裁) |
| 5-2 | Subagent 任务委托(委托八要素;结果聚合/去重/证据保留/主 Agent 复核) |
| 5-3 | Skill 系统(定义/生命周期/注册检索/编排/复用) |
| 5-4 | Agent Eval(14 项指标;Rule/Schema/Snapshot/Golden/LLM-as-Judge/Human;回归与 A/B) |
| 5-5 | Trace Analysis 与失败诊断(13 类失败归因)+ Eval 平台集成 |

**Lab5 验收**:六角色 Agent 产出可维护性分析报告;Golden Dataset ≥20 题;一次 Prompt 改动的回归对比报告(改进项/退化项)。→ M5

## 第 6 章 · 工程化、生产部署与可观测性(8 课时)

| 讲 | 主题 |
|---|---|
| 6-1 | 模型服务与推理部署(云/私有化/混合;vLLM/TGI/Triton 概念与选型) |
| 6-2 | 性能与成本优化(四级缓存体系;批处理并发;模型路由降级;读写分离落地) |
| 6-3 | 可观测性(三日志/Trace/Replay;四类指标与告警) |
| 6-4 | 版本/灰度/回滚 + MCP Server 生产化 + 平台封装(SDK/服务化/治理)+ Runbook |

**Lab6 验收**:Feature Flag 完成 Prompt 灰度并按指标回滚;Trace 中复现一次失败任务并 Replay 定位;成本报表按模型/工具分摊。→ M6

## 第 7 章 · 企业级综合项目与产品化落地(6 课时)

| 讲 | 主题 |
|---|---|
| 7-1 | DeerFlow 九条架构线解析(Gateway/Agent 工厂/工具装配/中间件管道/沙箱/子代理/技能/持久化) |
| 7-2 | 高阶案例:深度研究平台 + 软件工厂(架构蓝图/实现路径/二次开发) |
| 7-3 | Agent 产品化(场景判断/Chatbot-RAG-Workflow-Agent-脚本边界/业务拆解七步/交付指标/作品集与面试表达) |

**Capstone(选做其一)**:深度研究平台 MVP / 软件工厂 MVP / 自选业务 Agent。答辩式验收。→ M7

## 考核方案(草案)

| 项 | 占比 | 依据 |
|---|---|---|
| Lab 过程考核(M0~M6) | 40% | 每里程碑验收标准逐条核对 |
| 单元测试与 CI 质量 | 15% | 覆盖率 ≥80%、lint/typecheck 绿 |
| Capstone 答辩 | 30% | 作品集 + 数据证明(成功率/成本/延迟) |
| 面试表达(技术叙事) | 15% | 用项目数据讲工程能力的清晰度 |

## 教学质量回路

学员 Eval 平台数据(任务成功率/失败聚类)→ 每章复盘 → 调整下一轮讲义与实验难度(课程自身的 Eval 护城河)。
