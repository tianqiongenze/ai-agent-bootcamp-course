## 五、答辩纪律

1. 答辩录像归档学习档案袋；引用数据必须可复核（现场打开证据）。
2. "业务方评委"提问以业务语言进行；技术评委不得替答辩人翻译行话。
3. 发现证据造假 = 全队作品分记 0 + 按诚信条款处理。
