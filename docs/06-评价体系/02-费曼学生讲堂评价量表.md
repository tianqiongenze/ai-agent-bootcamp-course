# 费曼学生讲堂评价量表

**（EVAL-03 ｜ 占总评 10%＝教师评 60% + 同伴互评 40% ｜ 每讲 30′随机抽讲）**

> 使用说明：授课计划标注的 6 次学生讲堂（第 3/5/8/10/13/15 讲）必组织；其余各讲随机抽 1–2 人用本量表快评。学生以"讲给非技术评委听懂"为达标线（费曼学习法核心：以教代学）。

---

## 一、讲堂规则

| 项 | 规定 |
|---|---|
| 时长 | 常规 3 分钟；期末费曼答辩 10 分钟（用 EVAL-05） |
| 听众 | 全班扮演"业务方评委"；提问须以业务视角提出（"这个数为什么和报表对不上"而非"索引结构是什么"） |
| 抽讲 | 每讲随机抽讲（学号轮盘），未被抽中者作为同伴评委全员参评 |
| 证据 | 讲堂录音归档；"讲不清的概念"记入个人补讲清单，下次讲堂优先复讲 |
| 评分 | 教师按本量表 §二 评（60%）；同伴按 §三 评（40%）；两项加权为该次讲堂得分 |

---

## 二、教师评分量表（100 分）

| 维度 | 权重 | 优秀（满档）锚点 | 得分 |
|---|---|---|---|
| **正确性** | 30 | 概念/指标/流程与 dap-v2 事实一致（如：FAQ 直答 420ms、评测 91.7%、五步管线顺序），无科学性错误 |  |
| **通俗化** | 25 | 用了贴切的类比（如"图书馆找书"喻 Schema Linking）且类比不产生误导；业务方评委能复述核心 |  |
| **结构性** | 20 | 有明确"问题→机制→证据"结构；开口 30 秒内能让听众知道要讲什么 |  |
| **证据意识** | 15 | 引用了真实日志/截图/数据而非"我记得大概是" |  |
| **应答** | 10 | 面对追问先承认边界再推理（"这个我没验证过，但按机制推测…"），不硬编 |  |
| **合计** | 100 |  |  |

## 三、同伴互评量表（每名评委 1 份，去极值取均分）

> 指导语：请以"你听懂了吗"为第一标准，不以"讲得炫不炫"为标准。

| # | 题目 | 是/否 |
|---|---|---|
| 1 | 听完我能用自己的话把核心概念复述给第三个人 |  |
| 2 | 讲者没有使用未解释的行话（出现行话时 1 分钟内给了解释） |  |
| 3 | 至少有 1 处类比或例子让我"原来如此" |  |
| 4 | 我没有听到明显的技术错误 |  |
| 5 | 如果我是业务方，这次讲堂解决了我的一个疑问 |  |

- 计分：每"是"＝20 分，满分 100；同伴均分 × 40% ＋ 教师分 × 60%。

## 四、常见失分样例（教师讲评用）

1. 把"自校验"讲成"AI 很聪明所以不会错"——正确说法：生成后经 sqlglot AST 白名单等护栏校验，防幻觉列名。
2. 引用未脱敏的门店名/人名——触发课程安全红线，本次记 0 并重讲。
3. 类比误导：把语义缓存（cosine≥0.92）讲成"一模一样才命中"——实际是相似度阈值。
