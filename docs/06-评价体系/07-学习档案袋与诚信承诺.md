## 一、学习档案袋（Portfolio）说明

每位学生建立个人学习档案袋（部门共用工件放部门档案），**结课时按周次顺序整理**，作为过程考核证据链与就业作品集素材。

### 1.1 档案袋目录结构

```
学号-姓名-档案袋/
├── 00-诚信承诺书（签字扫描件）
├── 01-任务工单/           # L01–L15 共 15 份（EVAL-01）
├── 02-PR记录/             # 每周 PR 链接清单 + 评审单（EVAL-02）
├── 03-费曼讲堂/           # 录音文件 + 互评量表（EVAL-03）
├── 04-里程碑/             # M1/M2/M3 验收单 + 证据截图（EVAL-04）
├── 05-综合项目/           # 项目报告 + 发布检查单 + 答辩录像（EVAL-05）
├── 06-笔试/               # 试卷与成绩
└── 07-反思与成长/         # 每月 1 篇 500 字工程反思（3 篇）
```

### 1.2 命名与提交规范

- 文件命名：`L07-工单-虚拟数据部3-张工.docx`（讲次-类型-部门-角色名）。
- 电子版每周日 22:00 前提交至课程平台；纸质件第 16 周随档案袋上交。
- 录音/录像统一 mp3/mp4，单文件 ≤50MB。

## 二、课程诚信承诺书（每生一份，第 1 周签署）

我已完整阅读《AI驱动的数据中台项目实战》课程标准与过程考核实施细则，郑重承诺：

1. **诚实报告**：所有工单、报告、PR 描述中的"已完成/已验证"均以实际验证为准；做不到的，写入"未验证/未完成清单"。我理解：**承认未完成不是失败，虚报完成才是**。
2. **数据真实**：提交的任何指标（准确率、时延、RPS、覆盖率）附原始证据，接受教师随时抽查原始日志比对。
3. **安全红线**：不将凭据/内部 Token 写入代码与文档；不对课程命名空间以外资源写操作；不将未脱敏数据带入任何提交物。
4. **协作诚信**：结对编程如实记录双方贡献；引用他人（含 AI 工具）产出时明确标注。允许使用 AI 辅助学习，但**答辩与讲堂中个人理解部分必须自己讲清**——讲不清的部分现场会追问。
5. **接受结果**：违反上述条款，接受细则 EVAL-00 §一.5 的处理（该项 0 分并重做；二次违规取消该项得分）。

## 三、每月工程反思写作提示（500 字 · 3 篇）

| 月份 | 提示主题 |
|---|---|
| 第 4 周末 | 这一个月里，"计划赶不上变化"的一次经历：六步法哪一步救了你？ |
| 第 9 周末 | 讲一次"护栏拦住了自己"的经历：当时觉得烦，后来觉得对？ |
| 第 14 周末 | 如果下学期你带新同学，你最想提前告诉他的一个"数据说话"瞬间。 |

反思不评分（不占分），但**缺失任何 1 篇，档案袋不予归档**，影响结课材料完整性认定。
