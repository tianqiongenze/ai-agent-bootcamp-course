# 实验 L16：发布门禁演练与综合项目终验

**（实验指导 ｜ 对应学习情境 L16 ｜ 企业站 2 学时 ｜ 实验⑯ ｜ M3 验收 + 答辩）**

| 项 | 内容 |
|---|---|
| 实验类型 | 综合演练（发布决策） |
| 实验环境 | 课程环境完整链路（readyz/冒烟/E2E/评测） |
| 分组 | 部门协作（发布经理/值班/评审记录） |
| 提交物 | 《发布检查单》签署版 + 综合项目终验材料包 |

---

## 一、实验目标

1. 【评价】执行发布门禁评审会：readyz 全绿 + 冒烟 9 项 + E2E + 评测 CI 全部通过才放行。
2. 【评价】对照 RUNBOOK 演练一次回滚预案（口头推演即可，不动真格）。
3. 【创造】完成综合项目终验材料包并通过费曼答辩（用 EVAL-05）。

## 二、环境与准备

- 发布检查单模板（对照 dap-v2 生产 RUNBOOK 口径）：readyz → 冒烟（含内部认证头）→ E2E → 评测集 → 备份确认 → 放行签字。
- 冒烟提醒：SSE 类接口限时用 `curl -m`；护栏测试必须带 `x-internal-token`。
- 材料包清单：M3 验收单全部证据 + 答辩 PPT + 演示脚本（含失败场景演示）。

## 三、实验步骤

### 步骤 1：发布检查单逐项执行（50′）

| # | 检查项 | 命令/方式 | 通过标准 | ✓/✗ |
|---|---|---|---|---|
| 1 | readyz 全绿 | `curl -s .../readyz` | 200 且各依赖状态 healthy |  |
| 2 | 冒烟 9 项 | 教师发放冒烟脚本 | 9/9 通过 |  |
| 3 | E2E | Playwright 无头跑核心链路 | 关键路径全过 |  |
| 4 | 评测集 | 班级评测 CLI | 准确率不低于基线；CI 报告在档 |  |
| 5 | 备份确认 | 备份产物存在与大小核对（参考生产 20MB NFS 备份口径） | 产物在档 |  |
| 6 | 回滚预案推演 | 口头：坏在一步怎么回 | 有明确回滚指令序列 |  |

✓ 验证点：六项全过才允许在检查单"放行"栏签字；任何一项不过 → 记录并进入"不放行"处置（这本身是成绩，不放行不是失败）。

### 步骤 2：不放行分支演练（20′）

教师随机指定一项注入失败（如冒烟第 3 项），各组演练：不放行决策 → 缺陷记录 → 影响面评估 → 修复路径。记录处置链。

### 步骤 3：综合项目终验与答辩（剩余时间 + 课堂答辩环节）

1. 材料包提交归档。
2. 费曼答辩 10 分钟（业务方评委在场）+ 专业对话 15 分钟，按 EVAL-05 评分。
3. 项目 retro（复盘）：本学期最值得保留的 1 个实践 + 最想改的 1 个流程，入部门档案。

## 四、常见坑与排障

| 现象 | 原因与处置 |
|---|---|
| 冒烟部分过部分不过但"差不多" | 发布没有"差不多"；逐项记录，缺陷项明确修复责任人 |
| 回滚推演说不出指令序列 | 平时部署不留痕的恶果；从本实验起记录每次变更命令 |
| 答辩演示只放成功路径 | 必须含 1 个失败场景演示（护栏拦截/降级），证明系统诚实 |
