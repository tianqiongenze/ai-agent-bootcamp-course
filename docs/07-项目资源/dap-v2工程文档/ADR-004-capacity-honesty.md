# ADR-004：100 万并发按设计+实测外推的诚实验收口径
状态：Accepted（用户决策）· 2026-10-29
背景：2 节点纯 CPU 集群（80C/252G，其中 worker1 实际可用 ~64C），LLM 推理路径物理上无法承载百万并发（个位数 req/s）。
决策：架构按 100 万并发设计（无状态 HPA/异步削峰/三级缓存/读写分离/SSE 连接池化）；验收=本集群实测容量上限（k6 阶梯）+ 单副本容量→线性外推公式→100 万所需节点规模，写入测试报告（HSA 铁律：实测值与外推值明确分列）。
后果：+诚实可核验；−不在本集群真实压出百万（声明 DEFERRED：需 ≥25 节点等规模集群实测）。
