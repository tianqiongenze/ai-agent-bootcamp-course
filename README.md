# 《AI驱动的数据中台项目实战》课程仓库

**AI-Driven Data Platform Project Practicum ｜ 德国双元制本土化教学 · 全套授课资料**

以真实投产的 **DAP-v2：Data Agent 数据中台平台** 为完整载体，按德国双元制教育模式（Duale Ausbildung）设计实施，辅以**费曼学习法**与**布鲁姆认知分类**，覆盖"架构规划 → 基础设施 → 智能查询 → 质量治理 → ETL 编排 → 测试发布"全生命周期的 96 学时项目实战课程。

| 课程代码 | 总学时 | 学时结构 | 适用专业 | 开课学期 |
|---|---|---|---|---|
| BDP-4102 | 96（16 周 × 6） | 理论 32 + 实践 64（1:2） | 大数据技术、人工智能技术应用（高职高专） | 第 5 学期 |

- **双元安排**：每周校内理实一体 4 学时（六步法：资讯→计划→决策→实施→检查→评价）＋ 企业实训站 2 学时（真实两节点 K8S 集群，向课程分支提 PR）。
- **教学方法**：每讲固定"学生讲堂"（费曼：讲不清 = 没掌握）；教学目标与考核按布鲁姆六层级标注命题。
- **评价方式**：IHK 式过程考核（任务单 30% + PR 15% + 学生讲堂 10% + 里程碑 15% + 综合答辩 20% + 笔试 10%）。

## 快速上手

### 教师

1. 备课：按周次读 `docs/03-教学方案/Lxx-*.md`（含六步法分钟级过程设计、重点难点突破策略、检查单）。
2. 授课：直接使用 `docs/04-课件PPT/Lxx-*.pptx`；如需调整，改教学方案 md 后运行 `python3 scripts/build_ppt.py` 重新生成（PPT 由教学方案驱动生成，改 PPT 不如改方案）。
3. 分发：`export/word/` 与 `export/pdf/` 内为全部文档的可分发版本。

### 学生

- 每周按《授课计划总表》对应讲次，领取实验指导（`05-实验指导/`）与任务工单（`06-评价体系/01-六步法任务工单模板.md`）。
- 企业站实践向课程分支提交 PR，评审标准见 `06-评价体系/03-企业站PR评审单.md`。
- 结课档案袋要求见 `06-评价体系/07-学习档案袋与诚信承诺.md`。

### 课随产动（长期维护机制）

载体项目 dap-v2 更新后：

```bash
./scripts/sync-from-project.sh          # 同步 ADR/SAD/TEST-REPORT/RUNBOOK 等证据文档
python3 scripts/build_ppt.py            # 如教学方案有修订，重出 PPT
python3 scripts/build_docs.py           # 重出 Word/PDF 导出
```

## 文档规范

- 所有 md 均为 GFM；表格口径与课程标准一致（学时/占比/指标）。
- 指标引用 dap-v2 真实数据：FAQ 直答 420ms、LLM 全链路 56s、held-out 评测 91.7%（CI 79.2–100）、k6 140RPS 拐点、105.9 万订单零售数仓。
- 诚实文化（HSA）：所有学生提交物含"未验证/未完成清单"栏；虚报按 0 分处理。
