## 第 0 章(讲 0-1)课程与平台总览

**要点**:岗位能力模型 → 平台 20 项能力地图 → 工业件(GraphQL/Pulsar/读写分离/多级缓存)在哪里。开场用"Demo 与生产之间隔着什么"引入。
**提问**:你现在的后端经验里,哪一项可以直接迁移到 Agent 工程?(限流重试/权限/日志)
**误区**:把课程当成"调 API 教程"——第一天就要立住"Agent 是分布式系统"的心智。

## 第 1 章(讲 1-1 ~ 1-4)

**1-1 LLM API 基础**:从 HTTP 调用迁移讲起;temperature/top_p/max_tokens 各自改变什么分布;Token 是成本与延迟的第一性约束。演示:改 max_tokens 看输出截断。
**1-2 Streaming**:为什么串行等待不可接受;SSE 帧格式逐字节讲;演示平台 SSE 端点;中断取消=省 Token。提问:流式下 Usage 怎么拿?(末块事件)
**1-3 Prompt**:System=岗位说明书;Few-shot 什么时候有效(格式敏感任务);注入演示:用户输入 "ignore previous instructions"。误区:Prompt 越长越好——无关信息稀释注意力。
**1-4 结构化输出与 Gateway**:Schema 是三方契约;反喂重试演示;ModelRouter fallback 演示(现场把主模型改坏)。收束 M1 里程碑。

## 第 2 章(讲 2-1 ~ 2-5)

**2-1 Function Calling**:模型不执行代码,只产出"调用意图";Schema 越清楚参数越稳。
**2-2 Registry**:六项能力;演示 @tool 装饰器 30 秒注册一个工具。
**2-3 治理与安全**:RBAC 分级;高危确认制;脱敏演示(审计日志里 api_key 已打码)。**重点讲测试隔离事故**:disable 曾污染共享 spec 导致 3 个测试连环失败——可变共享状态是工程大坑。
**2-4 MCP**:Client/Server/资源三概念;与 Function Calling 的分工("选工具"vs"接工具");接入文件系统 MCP 演示。
**2-5 集成**:审计事件进总线;CLI 调试入口。收束 M2。

## 第 3 章(讲 3-1 ~ 3-5)

**3-1 Loop**:五段循环;演示死循环熔断(连续 3 个相同动作)。提问:终止条件有几种?(finish/上限/死循环/取消)
**3-2 Planning**:何时不要 Planner(步骤稳定的任务用 Workflow)。
**3-3 State/Checkpoint**:9 态状态机逐态讲;演示 kill 后恢复。
**3-4 Sandbox**:三类边界;本地 vs Docker 差异;演示危险命令拦截。
**3-5 Harness/LangGraph/Codebase Agent**:把平台 Loop 映射到 StateGraph;两个典型任务演示。收束 M3。

## 第 4 章(讲 4-1 ~ 4-5)

**4-1 Context Engineering**:与 Prompt Engineering 的分界;Budget 装箱演示(压缩比报告)。
**4-2 Working Memory**:State 是事实,Memory 是认知。
**4-3 Memory 三层**:项目记忆演示(注入构建命令后 Agent 行为变化)。
**4-4 RAG 全链路**:分块六法选型;Hybrid+RRF 融合演示;Citation 红线(回答必须带文件+行号)。
**4-5 LLM Wiki**:知识四维评估;过期知识的危害。收束 M4。

## 第 5 章(讲 5-1 ~ 5-5)

**5-1 Multi-Agent 边界**:先问"要不要多 Agent";隔离与预算。
**5-2 委托八要素**:冲突=同判断面分歧;仲裁按证据数。演示冲突仲裁。
**5-3 Skill**:版本必须递增;场景匹配。
**5-4 Eval**:14 指标讲 6 个核心;LLM-as-Judge 何时不可靠(顺序偏置/自我偏好)。
**5-5 Trace Analysis**:四步归因法;回归双清单(improved/regressed)。收束 M5。

## 第 6 章(讲 6-1 ~ 6-4)

**6-1 推理部署**:vLLM/TGI/Triton 一句话定位;OpenAI Compatible 是解耦关键。
**6-2 性能成本**:四级缓存;读写分离(读己之写回主库!)。
**6-3 可观测**:Span 树;Replay=真实重执行。
**6-4 版本灰度**:六类版本对象;一致性哈希灰度演示;Runbook 纪律:一条告警一条处置。收束 M6。

## 第 7 章(讲 7-1 ~ 7-3)

**7-1 DeerFlow 九线**:每条线先讲 DeerFlow 再对照本平台实现,建立"读源码的能力"。
**7-2 两大案例**:深度研究平台 / 软件工厂的架构蓝图与七步实施。
**7-3 产品化**:五选一边界判断;业务拆解七步;面试表达模板(见题库);Capstone 答辩标准。

# 面试题库(附答题要点)

**基础篇**
1. Function Calling 的执行主体是谁?→ 模型只产出调用意图,执行在 Runtime;意图≠执行,中间隔着校验/权限/审计。
2. temperature 与 top_p 的区别?→ 截断分布 vs 温度缩放;别同时大改两者。
3. 为什么 Agent 系统必须结构化输出?→ 可校验/可重试/可降级;自然语言解析是脆弱点。

**架构篇**
4. 设计一个 Tool Registry 要考虑什么?→ 元数据/发现/版本/依赖/启停/权限/审计,九要素契约。
5. Agent Loop 怎么防死循环?→ 相同动作签名熔断 + max_iterations + 终止动作 + 取消。
6. Checkpoint 应该保存什么?→ 足以恢复执行的最小集:状态 + 步骤 + 观察历史;不是全量内存快照。
7. 读写分离下如何保证用户读到刚写入的数据?→ 读己之写场景路由主库;强一致基线读主库。

**质量篇**
8. 怎么证明你的 Agent 改版变好了?→ Golden Dataset + 回归双清单 + 指标对比数据。
9. LLM-as-Judge 的坑?→ 顺序偏置/长度偏置/自我偏好;重要结论用规则 Judge 或人工抽检。
10. 引用准确率怎么算?→ 引用是否支持结论(证据一致性),不是"有没有引用"。

**生产篇**
11. Prompt 灰度怎么做?→ Prompt 版本化 + Feature Flag 一致性哈希按比例 + 指标观察 + 一键回滚。
12. 成本治理三板斧?→ 分级路由(小模型优先)/ 多级缓存(命中率监控)/ 预算告警。
13. Sandbox 为什么本地和容器不是同一边界?→ 文件系统/网络/权限命名空间不同,逃逸面不同。

**叙事篇(作品集表达)**
14. 描述你的 Tool Runtime。→ 讲治理:九要素契约、三级风险、人工确认、审计脱敏,配测试数字。
15. 描述你的 Eval 体系。→ 讲数据:20 题 Golden Set,一次 Prompt 改动被回归拦住的真实案例。
